# NaN

Portafolio personal, con una sola página estática, que presenta mis proyectos públicos de código abierto, y ofrece un medio para contactarme vía correo o WhatsApp.

## Desarrollo

Requiere Node 22.12 o superior.

```sh
npm ci
npm run dev       # http://localhost:4321
npm run build     # → dist/
```

## Proyectos

Los proyectos no se escriben en el código, se leen de la API de GitHub. El nombre, la descripción y el enlace de cada uno se editan en sus propios repositorios.
